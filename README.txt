KAPIBARA.HU v3

A v3 egy interaktív statikus életmódportál-prototípus:
- teljes reszponzív kezdőoldal
- témakörök
- cikkkereső
- kategóriaszűrés
- beépített cikkolvasó modal
- 7 részes Kapibara-kihívás
- kihívás teljesítésének helyi mentése
- heti progress sáv
- hírlevél-feliratkozási DEMÓ (valós email küldés nincs bekötve)
- mobil navigáció
- SEO alapok

Telepítés:
A ZIP kibontása után a tartalmát töltsd fel a tárhely webroot könyvtárába, például public_html.

A következő fejlesztési lépés lehet a valódi CMS/admin felület, adatbázis, működő hírlevél, külön cikkoldalak és saját képi arculat.
